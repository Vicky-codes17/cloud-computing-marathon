# Day 1 – Git Basics

## Objective

Understand the basics of Git and practise creating and managing a local repository.

## Topics Practiced

1. Introduction to Git
2. Installing Git
3. Git configuration
4. Repository initialization
5. File creation
6. Staging changes
7. Committing changes

## Commands Practiced

### 1. Check Git Installation

```bash
git --version
```

### 2. Configure Git

```bash
git config --global user.name "Vicky-Codes17"
git config --global user.email "rameshvignesh0706@gmail.com"
```

### 3. Create a Repository

```bash
mkdir my-project
cd my-project
git init
```

### 4. Create a New File

```bash
touch my_git_workspace.py
```

### 5. Check Repository Status

```bash
git status
```

### 6. Stage Changes

```bash
git add my_git_workspace.py
```

### 7. Commit Changes

```bash
git commit -m "My Git Learning Progress Journey"
```

## What I Learned

- How to check whether Git is installed.
- How to configure my Git identity.
- How to create and initialize a local repository.
- How to create files inside a project.
- How to stage changes before committing.
- How to save changes using a Git commit.

Completed my first Git practice session and learned the basic Git workflow.
